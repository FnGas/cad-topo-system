# CAD 弱电点位与网络拓扑存档系统

这是一个基于 Flask、SQLite 和 ezdxf 的 CAD 弱电点位管理系统。系统可以导入 DXF 建筑底图，在图纸上增加摄像头、门禁终端、网络设备和说明文字，建立设备之间的网络连线，并将结果保存、导出为 DXF。

系统支持将导出的 DXF 再次导入。新版导出的 DXF 会在文件内部保存点位和连线属性，因此再次导入后，原点位仍然是系统中的可编辑对象，而不是普通的 CAD 底图图形。

## 功能特性

- 导入 `.dxf` 格式的 CAD 底图。
- 支持解析常见 DXF 图元：直线、轻量多段线、多段线、圆、圆弧、文字和多行文字。
- 支持递归解析 DXF 块引用（`INSERT`）。
- 支持创建和编辑以下点位：
  - 摄像头：支持方向角度；
  - 门禁/终端设备；
  - 网络设备；
  - 说明文字。
- 支持填写设备名称、IP 地址、VLAN 等属性。
- 支持点位之间建立拓扑连线，并填写连线类型和说明。
- 支持批量生成网格点位和 IP 地址递增。
- 支持 IP 地址重复检查。
- 支持点位、连线、图标比例和项目名称保存到 SQLite。
- 支持按 CAD、摄像头、终端、网络设备、连线和文字图层选择导出内容。
- 支持导出 CAD 时选择是否显示 IP 地址。
- 支持游客只读模式和管理员修改模式。
- 支持修改游客密码和管理员密码。
- 支持生成示例楼层图和示例点位，便于首次验证系统。
- 支持新版 DXF 的结构化拓扑数据回导。
- 兼容识别旧版导出的 DXF：根据专用图层、设备图形和文字标注恢复点位及连线。

## 运行环境

- Python 3.9 或更高版本
- Flask
- ezdxf 1.4 或更高版本

## 初始化与安装

在项目根目录执行：

```powershell
pip install Flask ezdxf
```

如果已经安装依赖，可以直接跳过虚拟环境和安装步骤。

首次运行 `app.py` 时会自动完成初始化：

1. 创建 `topo_system.db` SQLite 数据库；
2. 创建 `settings`、`projects`、`nodes` 和 `links` 表；
3. 写入默认访问密码；
4. 创建 `uploads` 目录（如果目录不存在）。

系统不需要手动执行数据库迁移脚本。数据库文件和上传的 DXF 文件默认位于项目根目录：

```text
topo_system.db
uploads/
```

## 启动系统

在项目根目录执行：

```powershell
python app.py
```

启动成功后，在浏览器访问：

```text
http://[redacted-ip]:5000
```

程序默认监听 `[redacted-ip]:5000`，因此也可以使用同一局域网内计算机的 IP 地址访问，例如：

```text
http://[redacted-ip]:5000
```

## 默认权限

系统包含两种权限：

| 模式 | 默认密码 | 权限 |
|---|---|---|
| 游客预览 | `123456` | 查看项目、查看底图和点位 |
| 修改图纸 | `admin123` | 导入、编辑、删除、连线、保存、导出和修改密码 |

首次登录后，建议进入“修改密码”功能修改默认密码。密码保存在 SQLite 的 `settings` 表中。

## 基本使用流程

### 1. 创建项目

进入“修改图纸”模式后，可以选择以下任一方式创建项目：

- 点击“+ 示例图纸”，生成内置楼层平面图和示例点位；
- 点击“导入 CAD 图纸”，上传自己的 `.dxf` 文件，并填写项目名称。

上传后，系统会解析 DXF 图元并计算图纸边界，用于前端画布缩放和点位显示。

### 2. 添加和编辑点位

在图纸上选择点位类型并点击画布，可以新增点位。选中已有点位后，可以在右侧编辑：

- 点位名称或文字内容；
- IP 地址；
- VLAN；
- 摄像头角度；
- 点位坐标。

修改完成后点击保存。删除点位时，与该点位相关的连线也应一并处理。

系统会在保存时检查 IP 地址是否重复；重复时保存会失败并提示冲突地址。

### 3. 建立拓扑连线

选择连线功能后依次点击两个点位即可建立连接。可以为连线设置：

- `cat6` 网线；
- 光纤；
- `rvv` 等线缆类型；
- 连线说明。

### 4. 批量生成点位

使用“批量生成点位”功能，填写起始名称、数量、行列布局和 IP 地址递增规则，即可在指定区域快速创建规则排列的设备点位。

### 5. 保存项目

点击保存后，项目名称、图标比例、所有点位和连线会写入 SQLite。项目列表会显示点位数量和连线数量。

## DXF 导出和再次导入

点击“导出 CAD”后，系统会在原始 DXF 的基础上生成拓扑图形：

- `TOPO_CAMERA`：摄像头；
- `TOPO_TERMINAL`：门禁/终端；
- `TOPO_NETWORK`：网络设备；
- `TOPO_LINK`：拓扑连线；
- `TOPO_TEXT`：说明文字。

导出文件同时包含两类内容：

1. 普通 CAD 图形，用于在 AutoCAD 等软件中查看和打印；
2. 系统专用拓扑数据，用于再次导入时恢复可编辑点位。

系统会将拓扑 JSON 写入 DXF 的 `XRECORD`，并使用 `CAD_TOPO_SYSTEM_DATA` 作为数据名称；系统生成的 CAD 图形会带有 `CAD_TOPO_SYSTEM` 扩展标记。

再次导入新版导出文件时，系统会：

1. 读取 DXF 内的点位、连线和图标比例；
2. 删除系统生成的静态点位图形，避免与可编辑点位重复；
3. 保留原始建筑底图；
4. 将点位和连线重新写入新项目数据库。

因此，重新导入后可以继续移动、修改、删除点位或重新建立连线。

### 旧版导出文件兼容说明

旧版导出文件没有保存完整的结构化拓扑数据，系统会根据以下信息尽力恢复：

- 专用图层名称；
- 摄像头圆形和扇形图形；
- 终端和网络设备矩形图形；
- 点位旁的文字标注；
- `TOPO_LINK` 图层中的连线。

旧文件中不存在的信息无法恢复。例如，导出时隐藏的 IP 地址不会出现在文件中，旧版未保存的线缆类型会按默认 `cat6` 恢复。建议使用当前版本重新导出一次，以获得完整的回导能力。

## 数据备份

系统数据由两部分组成，备份时应同时保存：

- `topo_system.db`：项目、点位、连线和设置；
- `uploads/`：项目所引用的 DXF 文件。

只备份数据库而不备份 `uploads/`，项目可能因为找不到对应 DXF 文件而无法正常加载。建议在停止服务后复制这两个对象，或在复制前确保没有正在进行的保存和导出操作。

## 常见问题

### 导入 DXF 失败

请确认文件扩展名为 `.dxf`，且文件可以被常见 CAD 软件正常打开。过于复杂或包含异常实体的文件可能需要先在 CAD 软件中清理、另存为较新版本后再上传。

### 导出的点位再次导入后仍然是底图

请确认使用的是当前版本导出的文件，并通过系统的“导入 CAD 图纸”功能上传。旧版文件只能使用图形识别方式恢复；若文件被其他软件重新保存后丢失 DXF 扩展数据，则无法使用新版的结构化恢复方式。

### 点位文字显示异常

导出时会使用 `simhei.ttf` 作为中文字体。若目标 CAD 计算机没有该字体，CAD 软件可能使用替代字体显示。点位数据本身不会因此丢失。
